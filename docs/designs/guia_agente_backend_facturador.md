# Integración con EMITE.ec

Esta documentación pública describe únicamente la interfaz utilizada por la extensión. Los diagnósticos de infraestructura, datos reales de contribuyentes y detalles internos del servidor no deben publicarse aquí.

Consulta [el contrato público](sincronizacion_emite.md). Los ejemplos deben utilizar identificadores ficticios y nunca credenciales reales. El servidor debe validar autenticación, autorización por empresa, estructura y tamaño del XML, correspondencia entre la clave solicitada y el documento, estado de autorización y operaciones idempotentes. Una validación de la extensión no sustituye un control del servidor.
