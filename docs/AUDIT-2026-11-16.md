# Auditoría técnica y de publicación

Fecha: 16 de noviembre de 2026. Base: commit `8e9f71e` (3.5.0). Resultado: candidato 3.6.0 con correcciones; publicación bloqueada por verificaciones externas pendientes.

## Alcance y límites

Se revisaron código, configuración, documentación y los 123 blobs accesibles de los 10 commits de las referencias locales, contrastadas con la rama pública main. No había otras ramas o etiquetas anunciadas por el remoto. Se confirmó mediante GitHub que el repositorio es público y existe un fork. No se revisaron todas las copias externas, objetos borrados, registros de GitHub, contenido de forks ni configuración productiva de EMITE.

No se detectaron patrones de claves privadas, tokens GitHub, claves AWS, JWT ni URLs de base de datos con contraseña. Se compararon además tres valores sensibles de archivos locales de configuración del backend sin encontrar coincidencias en los blobs. Es una búsqueda acotada y no una garantía de ausencia de secretos.

Sí existían datos personales tributarios reales y rutas locales en una guía pública, además de detalles innecesarios de implementación del servidor. Se reemplazaron en la versión 3.6.0 por documentación de integración genérica. Los datos de versiones anteriores permanecen en commits históricos y pueden conservarse en copias externas. Suprimirlos del historial requiere una operación coordinada; no se reescribió historia ni se hizo force-push. Los datos de soporte declarados por el proyecto se conservan como contacto público.

## Correcciones implementadas

| Prioridad | Hallazgo en 3.5.0 | Corrección local |
| --- | --- | --- |
| Alta | Mensajes de sincronización sin comprobar emisor; posibles ejecuciones concurrentes | Sólo popup propio puede iniciar sincronización; exclusión mutua y validación de pestaña |
| Alta | Clave accesible a content scripts mediante almacenamiento por defecto; destinos API configurables y redirecciones | Acceso TRUSTED_CONTEXTS, destino HTTPS exacto, sin redirecciones ni cookies EMITE |
| Alta | Lotes mezclaban páginas e IDs de enlace podían referirse a otra factura | Lotes por página, frame explícito, navegación confirmada y correspondencia del enlace con la clave |
| Alta | XML aceptado por subcadenas, incluyendo páginas HTML con declaración XML | DOMParser, raíz permitida, rechazo de errores/DTD/entidades y correspondencia con clave solicitada |
| Alta | Espera de tabla comenzaba después del clic, devolvía éxito al agotar plazo y podía repetir páginas | Huella previa al clic, plazo con error y avance confirmado; límite de recorrido explícito |
| Media | Timeout de 120 s incompatible con respuesta fetch de más de 30 s en MV3 | API 25 s incluyendo lectura del cuerpo; XML 15 s; aviso de operación interrumpida al reiniciar worker |
| Media | Ausencia de XML generaba SOAP lento y resultados parciales aparecían como éxito | Sin SOAP implícito; lista de fallidos y estado PARTIAL |
| Media | Anulaciones omitían tipo EMITIDOS y podían superar máximo del servidor | Tipo explícito, grupos de 50 y manejo de error |
| Media | Fórmulas y comillas sin escapar en CSV; importes con miles mal interpretados | Neutralización de fórmulas, escape CSV y conversión de separadores |
| Media | Descargas dependían de la vida del popup e importación dinámica no disponible | Ejecución en content script con control de operación y utilidades de nombres en worker |
| Media | Permisos comodín/localhost, fuente remota y falta de aviso de privacidad | Dos hosts HTTPS concretos, fuentes del sistema, política local y aviso visible |
| Baja | Marca inconsistente y configuración sin etiquetas accesibles | Dos variantes oficiales del logo, foco visible y etiqueta del control de configuración |

Los controles del cliente no sustituyen validación, autorización, idempotencia ni verificación tributaria del servidor. La revisión del código local del servidor produjo un informe privado separado con asuntos pendientes; este repositorio público no contiene esos detalles.

## Evidencia de verificación

- Diez tests automáticos de seguridad y regresión: destinos API, parámetros de privacidad, tipo de anulaciones, claves e importes, CSV, lotes por página/frame, XML ausente, navegación fallida, origen del mensaje, nombres de archivo, recuperación e inicialización idempotente del script.
- Análisis de sintaxis de todos los módulos JavaScript.
- Revisión en Chrome de la carga y controles del popup, logos y política, sin errores JS ni solicitudes externas al abrir el popup; comprobación de XML con DOMParser real.
- Prueba reproducible `npm run test:browser` con la extensión cargada en Chrome for Testing: portal simulado de dos páginas, cuatro comprobantes escaneados, cuatro sincronizados en lotes de dos, cuatro XML descargados con nombres esperados y lectura de API Key bloqueada desde content script. Todo usa datos ficticios y API interceptada; no es una prueba contra producción.
- Paquete generado con lista explícita de archivos de ejecución. No contiene historial Git, documentos internos, XML de contribuyentes o credenciales.
- Pendiente: prueba real completa contra SRI y backend desplegado, revisión de Chrome Web Store.

Consulta [los requisitos de publicación](CHROME-STORE.md). No existe evidencia de certificación ISO ni se declara cumplimiento íntegro por ejecutar estos tests.
